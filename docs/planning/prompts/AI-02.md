## Objetivo

Ligar o SOM real pelo servidor e trocar o menu pela fala livre: leitura direta quando confiante, etiqueta "entendido como" quando hesita, menu quando falha.

## Escopo

**Inclui:**

- Adaptador da rota de decisões com tempo máximo, novas tentativas e tabela de erros.
- Telemetria: tempo, custo e modelo resolvido no registro.
- Rota `POST /api/som/player-line`.
- Entrada livre no site com etiqueta de confirmação e correção abaixo de 7000 bp ou com `OTHER`.
- Comparação de instruções em português e em inglês num teste ao vivo manual, com resultado no PR.
- Modo de teste do servidor que injeta o falso do SOM.
- Script `npm run smoke:live` (manual, exige a chave, nunca no CI) com a leitura de 5 falas reais.
- Leitura com as 10 perguntas numa chamada, incluindo `blamed`; `MOVE` com alvo vira `APPROACH`, sem alvo a interface pede a célula.

**Não inclui:**

- Premissa (AI-04).

## Lista de testes (escreva primeiro)

```text
- given a fake fetch when reading a player line then the request body follows the contract
- given a 429 then a 200 when calling then the adapter retries once and succeeds
- given an HTTP 200 with an error field when calling then it is a failure
- given a reading with act confidence 6500 when rendering the input then the confirmation tag appears
- E2E: given a confident fake reading when sending then the act goes straight to the engine
```
