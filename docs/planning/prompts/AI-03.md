## Objetivo

Encenar cada ato resolvido com o modelo de texto real: pedido com esquema JSON, validação, nova tentativa, fala pronta como alternativa, cache e teto de custo.

## Leia antes

- [integração de IA](<../../architecture/ai-integration.md>) — §3, §5 a §9
- [arquitetura](<../../architecture/overview.md>) — §7

## Escopo

**Inclui:**

- Adaptador da rota de chat com `response_format` em esquema JSON.
- Validação, uma nova tentativa e fala pronta marcada como alternativa; recusas marcadas.
- Cache pelo pacote, modelo e versão do prompt.
- Teto de custo por conversa.
- Rota `POST /api/text/render`.
- No site: pedir a fala a cada `RenderRequested`, mostrar fala e gesto, indicar que o personagem vai falar.

**Não inclui:**

- Avaliação (EVAL-01).

## Entregáveis

- `packages/ai/src/openrouter/chat.ts`
- `apps/server/src/routes/text.ts`
- `apps/web/src/scene/staging/`

## Lista de testes (escreva primeiro)

```text
- given a fake fetch when rendering then the request carries the JSON schema and the package
- given an invalid line twice when rendering then the fallback line is returned and marked
- given the conversation budget exceeded when rendering then only fallback lines are used and the user is warned
- given the same package twice when rendering then the second comes from the cache
- E2E: given a fake text model when NPCs act then their lines appear with gestures
```
